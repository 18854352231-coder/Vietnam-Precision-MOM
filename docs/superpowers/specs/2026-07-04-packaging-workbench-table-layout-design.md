# 包装工作台列表列宽与顺序优化设计

## 背景

包装工作台在删除 `状态` 列后，列表可读性有所提升，但当前字段宽度分配仍然偏平均，导致高频识别字段和长文本字段显示不够均衡。

## 目标

- 只调整包装工作台列表现有字段的顺序和宽度。
- 提升 `框号`、`订单号`、`挤压批次号`、`客户名称`、`产品号`、`模具号` 的首屏可读性。
- 保持现有业务字段、页签、操作逻辑不变。

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不新增列表字段。
- 不删除现有列表字段。
- 不修改 `开工`、`批量开工`、`装托`、`报废` 流程。
- 不调整表格数据来源和筛选逻辑。

## 方案

### 列顺序

将高频识别字段前置，建议列表顺序调整为：

- `框号`
- `订单号`
- `挤压批次号`
- `客户代码`
- `客户名称`
- `产品号`
- `模具号`
- `炉次号`
- `挤压机台`
- `牌号`
- `班组`
- `长度(m)`
- `支数`
- `来源工序`
- `操作`

### 列宽策略

- 放宽长文本或高频字段：
  - `订单号`
  - `挤压批次号`
  - `客户名称`
  - `产品号`
  - `模具号`
- 压缩短字段：
  - `客户代码`
  - `挤压机台`
  - `牌号`
  - `班组`
  - `长度(m)`
  - `支数`
- 保持 `操作` 列足够宽，避免按钮换行或挤压。

## 风险与控制

- 风险：若只调列宽不调顺序，视觉改善有限；若改动过大，可能影响用户习惯。
- 控制：仅做轻量重排，仍保留全部原字段，且操作列位置不变。

## 验证

- 首屏优先看到 `框号 / 订单号 / 挤压批次号 / 客户名称 / 产品号 / 模具号`。
- 短字段不再占用过多宽度。
- `操作` 列按钮不换行。
- `npm run build` 通过。
