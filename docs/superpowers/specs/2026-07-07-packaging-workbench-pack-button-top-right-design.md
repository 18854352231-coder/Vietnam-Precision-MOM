# 包装工作台装托按钮移到右上角设计

## 背景

当前包装工作台的 `装托` 按钮位于主表每行的操作列中。随着 `包装中` 页签已经支持“先在展开子表选择短支，再执行装托”，用户希望把 `装托` 入口调整到页面右上角，和 `批量开工`、`来料报废` 保持同一操作区。

## 目标

- 在包装工作台右上角操作区增加 `装托` 按钮。
- `装托` 仅在 `包装中` 页签显示。
- 点击右上角 `装托` 时，基于主表当前勾选的单条数据执行。
- 保留已有“短支勾选 -> 装托弹窗 -> 确认扣减”的后续流程。
- 删除主表行内的 `装托` 按钮，避免重复入口。

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不修改短支子表多选逻辑。
- 不修改新装托弹窗样式和字段。
- 不修改装托完成后的扣减和移除逻辑。
- 不修改批量开工、来料报废、查看工艺文件逻辑。

## 方案

### 1. 右上角入口

- 在现有 `action-buttons` 区域新增 `装托` 按钮。
- 按钮仅在 `activeTab === '包装中'` 时显示。
- 按钮点击事件新增独立入口函数，用于统一做主表勾选校验后再进入现有短支装托流程。

### 2. 主表勾选规则

- 右上角 `装托` 必须基于主表勾选数据触发。
- 仅允许勾选 `1` 条主表数据执行装托：
  - 未勾选时，提示用户先选择主表数据。
  - 勾选多条时，提示只能选择一条进行装托。
- 被勾选的数据还必须处于 `包装中` 状态，否则不给进入装托流程。

### 3. 短支校验与弹窗复用

- 右上角装托在通过主表勾选校验后，继续调用当前已有的短支装托入口逻辑。
- 如果该主行未在展开子表中勾选短支，沿用当前提示“请先选择短支”。
- 新装托弹窗、生成栈板号、确认装托、数量扣减逻辑全部复用现有实现，不新增第二套流程。

### 4. 行内入口移除

- 删除主表操作列中的 `装托` 按钮。
- 保留同一列中的 `开工` 与 `查看工艺文件` 按钮。

## 风险与控制

- 风险：右上角 `装托` 与顶部批量操作共用主表勾选，若未限制单选，可能导致操作对象不明确。
- 控制：装托入口显式校验“必须且只能勾选 1 条”。

- 风险：用户只勾选主表、不勾选短支，可能误以为可以直接装托。
- 控制：继续保留现有短支校验提示，不改变原有业务约束。

## 验证

- 切换到 `包装中` 页签时，右上角显示 `装托` 按钮。
- 主表未勾选任何数据时点击 `装托`，出现提示。
- 主表勾选多条数据时点击 `装托`，出现“只能选择一条”的提示。
- 主表勾选单条 `包装中` 数据但未勾选短支时点击 `装托`，出现“请先选择短支”的提示。
- 主表勾选单条 `包装中` 数据且已勾选短支时，点击右上角 `装托` 能正常弹出装托弹窗。
- 主表操作列中不再显示行内 `装托` 按钮。
- `npm run build` 通过。
