# 包装工作台包装中短支装托设计

## 背景

包装工作台当前在主表 `包装中` 状态下已经提供 `装托` 按钮，并存在一套“物料装托 -> 标识卡预览”的流程，但该流程面向整框装托，尚不支持在有码料展开明细中先选择若干短支，再按所选短支执行装托。

本次需求要求在 `包装中` 页面支持短支多选装托，并在点击 `装托` 后弹出接近现场截图样式的装托弹窗，用户确认后视为装托完成。

## 目标

- 在 `包装中` 页签的有码料展开明细中支持多选短支。
- 在主表 `包装中` 行保留并使用 `装托` 按钮。
- 点击 `装托` 时，若已选短支，则弹出新的装托图片样式弹窗。
- 在新弹窗点击 `确定` 后：
  - 主表支数按所选短支数量合计扣减。
  - 当前主行的展开明细移除已装托短支。
  - 当主行无剩余短支或剩余支数为 `0` 时，该主行移出 `包装中`。

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不调整批量 `来料报废` 流程。
- 不修改 `待包装` 开工逻辑。
- 不修改现有工艺文件查看逻辑。
- 不引入后端接口，仅基于当前前端 Mock 数据完成交互。
- 不要求本次新弹窗接入真实打印，仅完成图片预览式确认和前端数据扣减。

## 方案

### 1. 短支选择方式

- 仅对有码料展开明细生效。
- 仅在主表当前页签为 `包装中` 时展示子表多选框。
- 选中状态按主表行维度保存，避免多行展开时选择混淆。
- 未选择任何短支时点击主表 `装托`，给出提示，不允许进入装托弹窗。

### 2. 主表装托入口

- 继续复用主表 `包装中` 行上的 `装托` 按钮作为唯一入口。
- 点击时先校验当前行是否存在已选短支：
  - 若没有，提示“请先选择短支”。
  - 若有，弹出新的装托弹窗。

### 3. 新装托弹窗

- 新增独立于旧“物料装托”弹窗的新弹窗，用于本次短支装托流程。
- 弹窗结构贴近现场截图，至少包含以下信息或输入项：
  - 标题：`装托`
  - 料框号/栈板编号
  - 良品数量（默认显示所选短支数量合计）
  - 班组
  - 完工框号/栈板编号输入框
  - `生成栈板号` 按钮
  - `取消`、`确定` 按钮
- 弹窗中的图片样式以当前页面静态结构实现，不要求接入图片上传或真实图片生成服务。

### 4. 装托完成后的数据处理

- 点击 `确定` 时校验：
  - 已存在选中短支
  - 已填写完工框号/栈板编号
- 校验通过后：
  - 从当前主行 `details` 中移除本次选中的短支项。
  - 统计所选短支数量总和，并从主行 `qty` 中扣减。
  - 清空该主行的短支选中状态。
  - 关闭装托弹窗。
- 若主行扣减后 `qty <= 0` 或 `details` 已清空，则将该行从 `tableData` 中移除，视为该框已完成装托。
- 若仍有剩余短支，则保留在 `包装中`，等待后续继续装托。

### 5. 与现有旧流程的关系

- 现有 `物料装托` / `物料标识卡` 相关逻辑先保留，避免影响其他既有流程。
- 本次 `包装中短支装托` 优先走新弹窗和新数据处理逻辑，不再依赖旧的标识卡预览弹窗作为主流程。

## 风险与控制

- 风险：主表 `qty` 与展开明细数量口径不一致，导致扣减后显示异常。
- 控制：以所选短支的 `qty` 合计值为唯一扣减依据，并在确认后同步更新主表与子表。

- 风险：多行展开时短支选择串行或错绑到其他主行。
- 控制：选中状态按主行 `id` 单独维护，装托完成后仅清空当前主行对应选择。

- 风险：旧装托逻辑与新装托逻辑共存，容易误触旧流程。
- 控制：主表 `包装中` 的 `装托` 按钮优先切到新流程，旧流程仅保留代码兼容，不作为本次入口。

## 验证

- 在 `包装中` 页签展开有码料明细时可勾选多根短支。
- 未勾选短支时点击主表 `装托` 会提示，且不弹窗。
- 勾选短支后点击 `装托` 会弹出新的截图样式装托弹窗。
- 弹窗中良品数量等于所选短支数量合计。
- 未填写完工框号/栈板编号时点击 `确定` 会提示。
- 点击 `确定` 后，当前主行 `qty` 正确扣减，已选短支从子表移除。
- 当当前主行没有剩余短支时，该行从 `包装中` 列表消失。
- `npm run build` 通过。
