# 包装工作台待包装隐藏班组列设计

## 背景

包装工作台当前四个页签共用同一张列表表格，`班组` 列会在所有页签中统一显示。根据当前业务要求，`待包装` 页签不需要展示该字段，但其他页签仍需保留。

## 目标

- 仅在 `待包装` 页签隐藏 `班组` 列。
- `包装中`、`已完工`、`报废列表` 继续显示 `班组` 列。
- 不影响 `shiftTeam` 数据字段本身。
- 不影响标识卡预览和打印中的班组信息。

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不删除 `shiftTeam` 字段。
- 不修改打印预览中的 `previewData.shiftTeam` 展示。
- 不调整开工、批量开工、装托、报废等业务逻辑。

## 方案

### 列显示规则

- 将列表中的 `班组` 列改为条件渲染。
- 当 `activeTab !== '待包装'` 时显示该列。
- 当 `activeTab === '待包装'` 时不显示该列。

### 保留内容

- 列表其他字段顺序和宽度不变。
- `shiftTeam` 仍保留在数据模型中。
- 预览标识卡中的 `裁切/包装班组` 继续显示。

## 风险与控制

- 风险：若误删字段而不是做条件显示，会导致其他页签也丢失班组列。
- 控制：只在表格列定义处增加条件渲染，不改数据源和打印逻辑。

## 验证

- `待包装` 页签不显示 `班组` 列。
- `包装中`、`已完工`、`报废列表` 仍显示 `班组` 列。
- 标识卡预览中的班组信息保持不变。
- `npm run build` 通过。
