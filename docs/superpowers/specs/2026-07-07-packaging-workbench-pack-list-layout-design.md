# 包装工作台包装中装托列表与布局优化设计

## 背景

当前包装工作台在 `包装中` 页签下，操作人员装托后，主表数量会扣减或整行消失，但页面上缺乏一个直观的地方查看“本次操作到底生成了哪些托盘”。
为了让现场操作更顺手，需要增加一个“已装托列表”来展示生成的记录，并支持对误操作的数据进行撤销。

## 目标

- 优化 `包装中` 页签的布局，改为“左右分屏”。
- 右侧固定展示“已装托列表”。
- 支持在右侧列表对装托记录进行“撤销”，并将数量/短支退回至主表。

## 范围

### 纳入本次改造
- `src/views/extrusion/PackagingWorkbench.vue` 仅在 `activeTab === '包装中'` 时采用左右布局。

### 不在本次范围
- 不影响“待包装”、“已完工”、“已报废”等其他页签的布局（保持全屏列表）。
- 不修改原有的弹窗字段、有码/无码分支逻辑，仅接管弹窗确认后的数据流向。

## 方案

### 1. 左右分屏布局
- 当 `activeTab === '包装中'` 时，表格区域分为左右两块：
  - **左侧（主表区）**：占据约 `calc(100% - 380px)` 宽度，继续显示待装托的料框与短支。
  - **右侧（已装托区）**：占据 `380px` 宽度，采用卡片或面板样式，标题为“已装托记录”。
- 当切换到其他页签时，恢复为原有的单表全屏布局。

### 2. 右侧列表数据结构
- 新增 `packedRecords = ref([])` 用于存储本次装托生成的记录。
- 列表展示字段：
  - **完工栈板号**
  - **良品数量**
  - **班组**
  - **装托时间**
  - **操作**（撤销按钮）
- 数据来源：每次在装托弹窗点击“确定”后，生成一条新记录并 `unshift`（插到最前）到 `packedRecords` 中。

### 3. 数据退回机制（核心）
为了保证撤销时能完整退回数据：
- 在生成装托记录时，将当前主行数据的“完整快照”深拷贝一份保存在记录中（`sourceRowSnapshot`）。
- 有码料记录中还需要保存本次消耗的短支数组（`packedDetails`）。

**撤销逻辑**：
1. 点击“撤销”按钮。
2. 查找左侧 `tableData` 中是否还存在对应的原主行（通过 `id` 匹配）：
   - **如果存在**：把 `qty` 加回去。如果是有码料，把 `packedDetails` 里的短支 `push` 回子表 `details`。
   - **如果不存在**（说明之前装完扣减到 0 被移除了）：将 `sourceRowSnapshot` 恢复到 `tableData` 中，重置其 `qty` 为本次退回的数量，`details` 恢复为退回的短支。
3. 从 `packedRecords` 中移除该条装托记录。

## 风险与控制
- **风险**：左右分屏导致左侧主表宽度受挤压，横向滚动条变长。
- **控制**：右侧列表保持紧凑（380px），仅保留核心字段，避免过度侵占左侧空间。
- **风险**：退回时主表数据错乱或找不到原行。
- **控制**：强制在装托时深拷贝原行数据快照，确保任何时候都能完美复活被移除的行。

## 验证
- 切换到 `包装中` 页签，显示左右分屏布局；切换到其他页签，恢复单表全屏。
- 选中有码料装托后，右侧列表出现新记录，左侧数量扣减。
- 点击右侧该记录的“撤销”，记录消失，左侧数量与短支恢复。
- 选中无码料装托至剩余数量为 `0`，左侧该行消失，右侧出现新记录。
- 点击右侧记录的“撤销”，左侧该行重新出现，且数量恢复正确。
