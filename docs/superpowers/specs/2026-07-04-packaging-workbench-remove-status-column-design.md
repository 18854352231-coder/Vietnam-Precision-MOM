# 包装工作台删除状态列表字段设计

## 背景

包装工作台当前已经通过页签区分 `待包装`、`包装中`、`已完工`、`报废列表` 四类数据，表格中继续展示 `状态` 列会造成信息重复。

## 目标

- 删除包装工作台表格中的 `状态` 列。
- 保留页签、状态流转和按钮显隐逻辑不变。

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不删除内部 `status` 字段。
- 不调整 `待包装 / 包装中 / 已完工 / 报废列表` 页签。
- 不修改开工、装托、报废等状态流转逻辑。

## 方案

### 页面调整

- 删除表格中的 `状态` 列定义。
- 其他列表列顺序保持不变。

### 保留逻辑

- `activeTab` 继续作为页签筛选条件。
- 行数据中的 `status` 字段继续作为内部流转状态使用。
- 操作列中 `开工`、`装托` 继续基于 `row.status` 控制显隐。

## 风险与控制

- 风险：误删 `status` 相关逻辑会影响页签筛选或按钮显示。
- 控制：仅删除表格列定义，不触碰 `filteredTableData`、开工、装托、报废逻辑，并执行构建验证。

## 验证

- 包装工作台表格中不再显示 `状态` 列。
- 页签切换仍可正常显示对应数据。
- `待包装` 仍显示 `开工`，`包装中` 仍显示 `装托`。
- `npm run build` 通过。
