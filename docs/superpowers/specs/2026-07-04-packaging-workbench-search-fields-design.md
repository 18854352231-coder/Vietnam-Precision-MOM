# 包装工作台搜索项扩展设计

## 背景

当前包装工作台顶部仅支持 `框号` 和 `挤压批次号` 搜索，无法按客户、模具、炉次或时间范围快速定位目标数据，检索能力不足。

## 目标

- 在包装工作台顶部新增 `时间范围` 搜索框。
- 新增 `客户名称`、`模具号`、`炉次号` 搜索框。
- 保留现有 `框号`、`挤压批次号` 搜索框。
- 搜索逻辑继续采用当前页面的前端本地过滤方式。

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不修改页签逻辑。
- 不修改开工、装托、来料报废、打印等业务流程。
- 不接入后端接口搜索。

## 方案

### 搜索区字段

新增并保留以下搜索项：

- `框号`
- `挤压批次号`
- `客户名称`
- `模具号`
- `炉次号`
- `时间范围`

### 时间范围规则

- 使用 `el-date-picker`
- 类型使用 `datetimerange`
- 过滤字段使用列表数据中的 `finishTime`
- 为支持时间筛选，补充包装工作台 mock 数据中的 `finishTime` 字段

### 搜索逻辑

- `框号`、`挤压批次号`、`客户名称`、`模具号`、`炉次号` 使用模糊匹配
- `时间范围` 按 `finishTime` 落在开始和结束时间之间进行过滤
- 搜索逻辑仍然基于 `filteredTableData` 计算属性实现

### 重置逻辑

- 点击 `重置` 时，清空全部关键字搜索项
- 同时清空 `时间范围`

## 风险与控制

- 风险：现有 mock 数据缺少时间字段，新增时间范围后若不补值会导致筛选无效
- 控制：统一为当前列表数据补充 `finishTime`
- 风险：时间字符串比较不准确
- 控制：过滤时显式转成时间戳后再比较

## 验证

- 搜索区可见 `客户名称`、`模具号`、`炉次号`、`时间范围`
- 输入关键字后列表可正确过滤
- 选择时间范围后列表可按 `finishTime` 过滤
- 点击 `重置` 后所有搜索项恢复为空
- `npm run build` 通过
