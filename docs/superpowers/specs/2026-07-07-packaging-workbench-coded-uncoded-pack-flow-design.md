# 包装工作台有码料与无码料装托流程设计

## 背景

包装工作台当前已支持在 `包装中` 页签通过右上角 `装托` 按钮触发装托流程，并且对有码料实现了“先在展开子表勾选短支，再弹出装托弹窗”的流程。

现场最新需求要求区分两类数据：

- `有码料`：仍需先勾选短支，再进行装托。
- `无码料`：不需要选择短支，直接输入装托数量即可。

## 目标

- 保持右上角 `装托` 作为统一入口。
- 主表仅允许勾选 `1` 条 `包装中` 数据后装托。
- `有码料` 保持当前短支勾选装托规则。
- `无码料` 不需要勾选短支，在装托弹窗中直接输入装托数量。
- 两种物料装托完成后都正确扣减主表数量；有码料还需同步移除已装托短支。

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不修改右上角 `装托` 的位置和触发方式。
- 不修改来料报废、批量开工、查看工艺文件逻辑。
- 不引入新的独立弹窗组件。
- 不接入后端接口，仅基于现有 Mock 数据实现前端交互。

## 方案

### 1. 统一入口，按物料类型分支

- 继续使用右上角 `装托` 按钮。
- 点击时仍先校验主表必须且只能勾选 `1` 条 `包装中` 数据。
- 校验通过后，根据主行 `isCoded` 分流：
  - `isCoded === true`：进入有码料装托分支
  - `isCoded === false`：进入无码料装托分支

### 2. 有码料规则

- 必须先在展开子表中勾选短支。
- 未勾选短支时点击 `装托`，提示“请先选择短支”。
- 装托弹窗中显示所选短支合计数量，作为只读数量展示。
- 点击 `确定` 后：
  - 按所选短支数量合计扣减主表 `qty`
  - 从当前主行 `details` 中移除已装托短支

### 3. 无码料规则

- 不要求展开子表，也不要求选择短支。
- 点击右上角 `装托` 后直接打开同一个装托弹窗。
- 弹窗中提供可编辑的 `装托数量` 输入框：
  - 默认值可取当前主行 `qty`
  - 最小值为 `1`
  - 最大值为当前主行 `qty`
- 点击 `确定` 后：
  - 直接按输入数量扣减主表 `qty`
  - 不涉及 `details` 处理

### 4. 弹窗展示策略

- 复用现有短支装托弹窗，不新建第二套弹窗。
- 弹窗根据 `selectedPackRow.isCoded` 切换字段展示：
  - 有码料：显示 `良品数量`
  - 无码料：显示 `装托数量` 输入框
- 其他字段如 `来料框号/栈板编号`、`班组`、`完工框号/栈板编号`、`生成栈板号` 按钮继续保留。

### 5. 装托完成后的统一规则

- 两种物料都必须校验已填写 `完工框号/栈板编号`。
- 扣减后若主表 `qty <= 0`，则将该主行从 `包装中` 列表移除。
- 若仍有剩余数量，则保留在 `包装中`，等待下次继续装托。

## 风险与控制

- 风险：有码料与无码料共用同一弹窗，若字段切换条件不明确，容易出现数量展示错误。
- 控制：以 `selectedPackRow.isCoded` 作为唯一分支条件，模板和提交逻辑都使用同一判断来源。

- 风险：无码料数量输入若不限制上下限，可能出现超出剩余支数的扣减。
- 控制：输入框设置 `min=1`、`max=current qty`，提交时再做一次数值校验。

- 风险：有码料和无码料共用完成逻辑后，可能误删无码料的 `details`。
- 控制：仅在有码料分支中处理 `selectedDetailIdsByRow` 和 `details` 移除，无码料分支只扣减主表 `qty`。

## 验证

- 勾选单条有码料主表数据但未勾选短支时，点击右上角 `装托` 会提示。
- 勾选单条有码料主表数据并勾选短支时，点击 `装托` 会弹出装托弹窗，并显示只读的合计良品数量。
- 勾选单条无码料主表数据时，点击 `装托` 可直接弹出装托弹窗，无需短支选择。
- 无码料弹窗中可输入装托数量，且数量不能超过主表剩余支数。
- 有码料确认后主表数量减少，且已选短支从子表移除。
- 无码料确认后主表数量按输入值减少。
- 两种物料在数量扣减至 `0` 时都从 `包装中` 列表移除。
- `npm run build` 通过。
