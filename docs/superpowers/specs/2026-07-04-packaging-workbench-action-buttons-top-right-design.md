# 包装工作台操作按钮右上角布局设计

## 背景

当前包装工作台的 `批量开工` 和 `来料报废` 按钮位于搜索区下方单独一排，视觉上偏左且与用户预期的右上角操作区不一致。

## 目标

- 将 `批量开工`、`来料报废` 按钮移动到搜索区同一行最右侧。
- 搜索表单继续保留在左侧。
- 不调整按钮业务逻辑与显示规则。

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不修改搜索字段和搜索逻辑。
- 不修改 `批量开工` 的显示条件。
- 不修改 `来料报废` 的禁用规则。
- 不调整列表、页签和打印逻辑。

## 方案

### 布局调整

- 将搜索区改为左右结构：
  - 左侧为搜索表单
  - 右侧为操作按钮组
- 按钮组固定在搜索区顶部右侧对齐。
- 搜索表单在可用空间内自动换行，不再把按钮挤到下方。

### 样式策略

- 搜索表单容器设置为 `flex: 1`
- 搜索区取消外层换行导致的按钮下沉问题
- 按钮组继续使用横向排列和固定间距

### 保留行为

- `批量开工` 仍只在 `待包装` 页签显示。
- `来料报废` 仍按勾选状态禁用。
- 查询、重置、时间范围和关键字搜索行为不变。

## 风险与控制

- 风险：搜索项较多时，表单可能压缩后影响换行观感。
- 控制：只调整外层布局，不缩小按钮，保持搜索表单在左侧自适应换行。

## 验证

- `批量开工`、`来料报废` 显示在搜索区右上角。
- 搜索表单仍正常换行显示。
- 查询、重置、批量开工、来料报废逻辑不受影响。
- `npm run build` 通过。
