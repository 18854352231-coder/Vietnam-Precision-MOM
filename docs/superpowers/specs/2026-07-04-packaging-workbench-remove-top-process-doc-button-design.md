# 包装工作台删除顶部查看工艺文件按钮设计

## 背景

包装工作台当前在页面右上角工具栏和列表操作列中都提供了 `查看工艺文件` 入口。根据当前需求，仅需删除右上角的顶部入口，保留列表中的逐条查看入口。

## 目标

- 删除包装工作台右上角工具栏中的 `查看工艺文件` 按钮。
- 保留列表操作列中的 `查看工艺文件` 按钮。
- 不影响工艺文件弹窗逻辑和其他业务按钮。

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不删除列表操作列中的 `查看工艺文件`。
- 不修改 `ProcessDocumentDialog` 组件。
- 不调整开工、批量开工、装托、来料报废逻辑。

## 方案

### 页面调整

- 删除顶部 `action-buttons` 区域中的 `查看工艺文件` 按钮。
- 保留 `批量开工` 和 `来料报废` 按钮原有位置和行为。

### 保留逻辑

- 行内 `查看工艺文件` 按钮继续调用 `viewProcessDocument(row)`。
- 现有工艺文件弹窗仍可从操作列打开。

## 风险与控制

- 风险：误删行内按钮会影响逐条查看工艺文件。
- 控制：只删除顶部工具栏中的按钮，不改操作列按钮定义。

## 验证

- 包装工作台右上角不再显示 `查看工艺文件` 按钮。
- 列表操作列中的 `查看工艺文件` 按钮仍可见且可点击。
- `npm run build` 通过。
