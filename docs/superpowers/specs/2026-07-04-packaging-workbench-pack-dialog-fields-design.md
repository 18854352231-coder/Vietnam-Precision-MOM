# 包装工作台装托弹窗字段精简设计

## 背景

包装工作台的“物料装托”弹窗当前仍保留 `包装方式`、`毛重`、`净重`、`总重` 等字段，但本次业务只需要包装人员填写托盘基础信息，不再要求在该弹窗内填写重量信息。

## 目标

- 删除装托弹窗中的 `包装方式` 字段。
- 删除装托弹窗中的 `毛重`、`净重`、`总重` 字段。
- 新增必填下拉字段 `类型`。
- `类型` 的下拉选项固定为：
  - `正常生产`
  - `验证料`
  - `客户需求`

## 范围

### 纳入本次改造

- `src/views/extrusion/PackagingWorkbench.vue`

### 不在本次范围

- 不调整打印预览的版式。
- 不让 `类型` 参与重量计算。
- 不让 `类型` 参与标识卡打印展示。
- 不修改报废、开工、已完工等其他流程。

## 方案

### 表单字段调整

装托弹窗保留以下字段：

- `托盘号`
- `类型`
- `本次装托数量`

删除以下字段：

- `包装方式`
- `毛重(kg)`
- `净重(kg)`
- `总重(kg)`

### 类型字段规则

- 字段名为 `类型`。
- 组件使用 `el-select`。
- 必填。
- 选项固定为：
  - `正常生产`
  - `验证料`
  - `客户需求`

### 提交流程

- 提交时仅校验：
  - `托盘号`
  - `类型`
  - `本次装托数量`
- 不再校验重量相关字段。
- 不再保留重量输入清洗逻辑。
- 生成托盘并预览标识卡的现有流程继续保留。

## 风险与控制

- 风险：删除重量字段后，旧脚本中若仍引用相关字段，可能导致空引用或无效校验。
- 控制：同步删除表单字段、默认值、输入处理函数和提交校验中的旧引用，并执行 `npm run build` 验证。

## 验证

- 打开装托弹窗后，仅显示 `托盘号`、`类型`、`本次装托数量`。
- `类型` 下拉仅包含 `正常生产`、`验证料`、`客户需求`。
- 未选择 `类型` 时提交会提示。
- 提交流程可正常进入标识卡预览。
- `npm run build` 通过。
