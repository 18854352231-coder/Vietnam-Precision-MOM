# 产品检验配置明细重构 Spec

## Why
在当前的产品检验配置页面中，“检验规则配置明细”列直接将所有规则内容以文本形式平铺展示。当规则项较多时，会导致表格行高过大，界面显得杂乱，影响用户的浏览体验和页面整洁度。将其改为按钮并以弹窗形式展示，能够有效提升表格的整洁性和用户体验。

## What Changes
- 修改 `InspectionConfig.vue` 中的表格列“检验规则配置明细”，将其内容替换为一个“查看明细”按钮。
- 新增一个“规则配置明细”弹窗，用于在点击按钮后展示具体的检验规则列表（包含检验项目、标准值、公差、单位等信息）。

## Impact
- Affected code: `src/views/quality/InspectionConfig.vue`

## MODIFIED Requirements
### Requirement: 检验规则配置明细展示
**原有逻辑**：直接在表格列中通过循环遍历展示所有检验项和数值。
**修改后逻辑**：
- **WHEN** 某产品对应工序有检验规则时，表格列中显示“查看明细”按钮。
- **WHEN** 用户点击“查看明细”按钮，
- **THEN** 弹出一个对话框，以表格形式清晰展示该产品在该工序下的所有检验规则（包括检验项目、标准值、公差范围、单位）。
- **WHEN** 某产品对应工序没有配置规则时，
- **THEN** 表格列中显示文本“暂无规则配置”或禁用状态的按钮。
